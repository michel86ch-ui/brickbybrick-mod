Notre-Dame in the gameFirst in-game test of the mod building · 21 October 2026

The simplified Notre-Dame of the Extra Buildings mod, loaded into Brick by Brick for the first time: 24,291 brick slots in five construction sites (the game allows 8,192 per site), a plinth, the brick supply next to the cathedral and a walkable scaffold up to the spire and the bell towers. Nothing is built yet: every brick still has to be placed by hand.

3D preview of the design (brick list, construction sections) Source code on GitHub

Known issues in this test

  • The scaffold shows the wrong texture (the game's scaffolding material is a texture atlas, the mod's plain boxes show all of it).
  • Some scaffold parts rest on roofs that are not built yet, so they hang in the air for now.
  • The five construction sites share one area, so their progress panels overlap.

Unofficial fan mod, not made by the game's developers. Screenshots from a test world.
